# Sleep Quality Predictor

A Machine Learning-powered web application that predicts sleep quality as **Good**, **Average**, or **Poor** based on your sleep and lifestyle habits, and provides personalized wellness suggestions.

> **Disclaimer:** This tool is for general wellness and educational purposes only. It does not provide medical advice, diagnosis, or treatment.

---

## Features

- 9 sleep & lifestyle input fields (sleep duration, bedtime, wake time, caffeine, exercise, screen time, stress, mood, interruptions)
- Real ML prediction using a trained scikit-learn pipeline
- Confidence score with animated progress bar
- Personalized wellness suggestions based on your inputs
- Prediction history stored in browser localStorage
- Interactive trend charts (Chart.js) for sleep, stress, screen time, and quality
- Responsive design (desktop, tablet, mobile)
- Glassmorphism UI with animated star background

---

## Architecture

```
User Input Form
      |
      v
  Flask /predict API
      |
      v
  Validate Input (preprocessing.py)
      |
      v
  scikit-learn Pipeline (StandardScaler + Encoders + SVM)
      |
      v
  Prediction + Confidence
      |
      v
  Recommendation Engine (recommendations.py)
      |
      v
  JSON Response -> Frontend Display -> localStorage History
```

## Dataset

**Type:** Synthetic (generated by `ml/create_dataset.py`)

The Kaggle "Sleep Health and Lifestyle Dataset" was evaluated but lacks 6 of 9 required UI input features. A synthetic dataset with 500 samples is used instead, with realistic scoring-based labels and Gaussian noise.

| Column | Type | Description |
|--------|------|-------------|
| sleep_duration | float | Hours of sleep (3-11) |
| bedtime | string | HH:MM format |
| wake_time | string | HH:MM format |
| caffeine | categorical | None / Low / Moderate / High |
| exercise_duration | float | Minutes (0-120) |
| screen_time | float | Minutes before bed (10-180) |
| stress_level | float | Scale 0-10 |
| mood | categorical | Happy / Neutral / Sad / Anxious |
| interruptions | categorical | Yes / No |
| **sleep_quality** | **TARGET** | **Good / Average / Poor** |

---

## ML Algorithms

Four models are trained and compared automatically:

1. **Logistic Regression** - Linear baseline
2. **Decision Tree** - Non-linear, interpretable
3. **Random Forest** - Ensemble of decision trees
4. **SVM (Support Vector Machine)** - Kernel-based classifier

The best model is auto-selected by highest weighted F1 score.

## Usage

```bash

```

```bash

```

```bash

```

```
http://127.0.0.1:5000
```

---

## API

### POST /predict

**Request:**
```json
{
    "sleep_duration": 7.5,
    "bedtime": "23:00",
    "wake_time": "06:30",
    "caffeine": "Moderate",
    "exercise": 30,
    "screen_time": 60,
    "stress": 6,
    "mood": "Neutral",
    "interruptions": "No"
}
```

**Response:**
```json
{
    "prediction": "Good",
    "confidence": 0.87,
    "tips": [
        "Great news! Your sleep habits look healthy.",
        "Your caffeine intake is moderate. Try to avoid caffeine within 6 hours of bedtime.",
        "Consider reducing screen exposure before bed."
    ]
}
```
